# Destiny 2 Pattern Tracker Pro

A high-performance web application to track weapon pattern progress using the Bungie.net API.

## 🚀 Tech Stack
* **Frontend:** Angular 19+, TypeScript, Tailwind CSS
* **Backend:** FastAPI, Python 3.12+, Uvicorn
* **Infrastructure:** Docker, AWS (S3/App Runner), GitHub Actions
* **Database:** PostgreSQL (for manifest caching)

## 🛠️ Local Setup
1. Clone the repo.
2. Setup the Python virtual environment in `/backend`.
3. Install Angular dependencies in `/frontend`.
4. Create a `.env` with your Bungie API credentials.
